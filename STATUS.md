_Updated 2026-10-02 (first night)._

**PUBLISHED**: https://andrewnakas.github.io/pokered-cleanroom/ (repo https://github.com/andrewnakas/pokered-cleanroom,
`main` + `gh-pages`). Live page checked in headless Edge: boots, picture, sound, input. Update with
`sh tools/publish.sh push "message"` (rebuilds, refuses to push unless the taint scan prints FAILING: 0).

## What works

- **Round trip**: the untouched pret/pokered clone builds `pokered.gbc` / `pokeblue.gbc` with the sha1s in
  `roms.sha1` (rgbds 1.0.4). The ROM the user downloaded to `D:/` has the same sha1 as the Red target; it sits in
  `D:/n64work/pokered/rom/` as a reference only and is used by nothing.
- **Clean build**: `sh games/pokered/build_clean.sh` builds Red and Blue from a copy of the tree in which all 668
  retail PNGs are deleted and the 509 pictures the two games use are generated by `games/pokered/generate.py`
  from `games/pokered/spec/assets.json` (coarse facts) + our own drawing code and briefs. No overflow, both ROMs link.
- **Boots and plays**: headless runs (PyBoy, `games/pokered/play.py`) go through the intro, naming screens, Red's
  house; text, menus, text boxes, HP bars are readable (own heavy 6x7 font).
- **Web page**: `ports/ejs` (EmulatorJS 4.2.3 + gambatte) runs the clean ROM in headless Edge: picture, sound
  (audio buffers with signal), keyboard input; Red / Blue switch; Game Boy touch pad; one tap starts game and
  sound (iframe friendly). Game Boy Color palette for the cartridge title (red tint for Red, blue for Blue).
- **Taint**: `python -m cleanroom.gb.taint <dirty> <clean> games/pokered/spec/assets.json` -> 0 failing at the
  time of writing (re-run by `tools/publish.sh` before every push).

## Decisions (for review)

1. **Web route**: clean ROM + EmulatorJS/gambatte (as CLAUDE.md). Red first, Blue is the second ROM on the same page (`?v=blue`).
2. **Kept facts** (`extract_spec.py`, the only code that reads retail pictures): per picture size + bit depth + a 4x4
   grid of mean shade for the **whole** picture (per 16x16 frame for sprite strips) + a 1-bit silhouette for single
   drawn figures and sprites. Tile sheets, fonts and UI glyph sheets keep **no** silhouette (it would be a copy):
   they are redrawn from what each tile is.
3. **Coarse silhouettes for figures** (Pokemon, trainers, intro art): retail outlines have gaps, so a plain flood
   fill leaks and the "silhouette" becomes the retail line art. Gaps up to 6 px are closed and parts that are only a
   line are dropped. The figure's character comes from our brief (`cut`/`add` reshape it).
4. **Layout facts kept**: which tiles of a trimmed sheet are blank (the build trims trailing blanks) and, for the
   two pictures the build de-duplicates (intro Gengar, trade Game Boy), which tiles are equal (the code's tilemaps
   index them).
5. **Kept as data/code**: maps, blocksets, tilemaps, text, music + sound effect + cry sequences, SGB/GBC palette tables.
6. **Taint rule for small low-colour tiles** (details in `docs/PLATFORM_GAME_BOY.md` and the header of
   `cleanroom/gb/taint.py`): every clean 8x8 tile is looked up among all 16,465 retail tiles. Coincidence (not
   failing) = bars/blank/solid; rectilinear tiles (<= 4 distinct rows and columns: box corners, frames);
   <= 6 drawn pixels, or 2 shades with <= 14 shade changes; in silhouette pictures, tiles whose interior is one flat
   shade or under 12 px. Failing = any other identical tile; sheets: a tile with >= 80% of drawn pixels equal in place;
   silhouette pictures: >= 90% of interior pixels equal; `.pic` streams sharing a 32 byte run.
   Chance collisions inside figures are fixed through `games/pokered/salts.json` (tile numbers only).
7. **Font**: a plain 5x7 font collided with retail glyphs (20 identical tiles), so the font is a heavier design of
   our own (doubled upright strokes); the taint scan passes it.
8. **Title logo**: the word is typeset in our own block lettering, not an imitation of the trademark logo; the
   Game Freak splash emblem is an emblem of our own.
9. **Copyright lines on the title/splash** keep the game's text (re-typeset).
10. **No voices** in this game: no practice pack, no TTS.
11. **Helpers**: tilesets, UI sheets and the per-creature briefs are independent batches done by subagents under
    `docs/TILESET_BRIEF.md` / `docs/PICTURE_BRIEF.md` (look at retail only to learn what a thing is; draw our own).
